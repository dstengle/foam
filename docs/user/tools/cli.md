# Command Line Interface

The Foam CLI provides command-line tools for working with your Foam workspace.

## Installation

The CLI is available as a separate package:

```bash
npm install -g foam-cli
```

Or use it directly with `npx`:

```bash
npx foam-cli create-note --title "My Note"
```

## Available Commands

### `foam create-note`

Create new notes from templates with full variable expansion support.

**Basic usage:**

```bash
foam create-note --title "My Note"
```

**With template:**

```bash
foam create-note --template .foam/templates/daily-note.md --date 2024-01-15
```

**With custom variables:**

```bash
foam create-note \
  --template .foam/templates/meeting.md \
  --title "Team Meeting" \
  --variable PROJECT=FoamCLI \
  --variable ATTENDEES="Alice, Bob"
```

See the full documentation in the [foam-cli package](../../../packages/foam-cli/README.md).

## Template Variables

The CLI supports all Foam template variables:

- `$FOAM_TITLE` - Note title
- `$FOAM_SLUG` - URL-friendly slug of the title
- `$FOAM_DATE_YEAR`, `$FOAM_DATE_MONTH`, `$FOAM_DATE_DATE` - Date components
- Custom variables via `--variable` option

## Future Commands

Additional commands planned for future releases:

- `foam init` - create a new foam workspace
- `foam janitor` - run [[workspace-janitor]] in current workspace
- `foam migrate <tool>` - migrate from tools like roam exports, obsidian and more
